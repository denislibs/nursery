Рисование on · pipe · throttle

Каждый штрих это один for await по pointermove, который заканчивается на pointerup. Никаких флагов и снятия обработчиков.

штрихов: 0 · точек: 0
for await (const down of on(canvas, 'pointerdown', { signal })) {
  const stroke = new AbortController();
  on(canvas, 'pointerup', { signal: stroke.signal })[Symbol.asyncIterator]().next().then(() => stroke.abort());
  for await (const move of pipe(on(canvas, 'pointermove', { signal: stroke.signal, buffer: 1 }), throttle(8))) {
    line(prev, move);
  }
}

Удерживай для подтверждения race · sleep

Гонка между «отпустил» и «прошло 1200 мс». Проигравший отменяется, поэтому таймер не срабатывает после раннего отпускания.

const outcome = await race([
  sig => once(button, 'pointerup', sig).then(() => 'released'),
  sig => sleep(1200, sig).then(() => 'confirmed'),
]);
