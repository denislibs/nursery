page.dump() живое дерево

Nursery.onUnhandled

Сюда попадают ошибки задач, которых никто не ждал, и зависшие задачи после grace.

Код

const page = new Nursery({ name: 'page', grace: 2000 });
const widget = page.child({ name: 'status', timeout: 1500 });
widget.spawn(sig => http.get('/status', { signal: sig }), { name: 'poll' });

for await (const e of http.sse('/ticker', { nursery: widget, reconnect: { delay: 500 } })) render(e);

await page.close();          // всё дерево: отмена, ожидание, cleanup, отчёт о зависших
