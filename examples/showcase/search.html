Наивный fetch без отмены

Каждое нажатие делает запрос, рендерится любой пришедший ответ. Жёлтое означает, что список показывает результат для устаревшего запроса.

в полёте: 0 · перетёрто устаревшим: 0

    latest() новый вызов отменяет старый

    Красные полосы это отменённые запросы: их ответ никогда не дойдёт до рендера. Сеть тоже освобождается, потому что AbortSignal доходит до fetch.

    в полёте: 0 · отменено: 0 · перетёрто: 0

      Код правой панели

      const search = latest((q, signal) => http.get('/search', { signal, query: { q } }));

for await (const e of pipe(on(input, 'input', { signal }), debounce(150))) {
  search(e.target.value).then(render).catch(ignoreAbort);   // старый ответ никогда не перетрёт новый
}
