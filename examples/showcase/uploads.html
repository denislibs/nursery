Файлы Queue · retry · onUploadProgress

Сервер читает тело медленно и иногда отвечает 503. Кнопка ★ поднимает приоритет ожидающего файла, × отменяет конкретный, пауза не трогает уже идущие.

Код

const uploads = new Queue({ concurrency: 3, signal: page.signal });

uploads.add(sig => http.post('/upload', {
  signal: sig, body: file,
  retry: { retries: 3, delay: 300, onRetry: (e, n, wait) => log(...) },
  onUploadProgress: (sent, total) => bar.style.width = `${sent / total * 100}%`,
}), { priority: starred ? 10 : 0, signal: fileCtrl.signal });

uploads.pause(); uploads.resume(); uploads.clear();
