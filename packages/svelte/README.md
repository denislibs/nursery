# @scopekit/svelte

Svelte 5 helpers for [scopekit](https://github.com/denislibs/scopekit): scoped effects, async state, latest-wins calls, event streams and workers tied to the component lifecycle.

```bash
npm i @scopekit/core @scopekit/svelte
```

Documentation and recipes live in the [repository](https://github.com/denislibs/scopekit#readme).
