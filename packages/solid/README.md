# @scopekit/solid

SolidJS primitives for [scopekit](https://github.com/denislibs/scopekit): scoped effects, async state, latest-wins calls, event streams and workers tied to the component lifecycle.

```bash
npm i @scopekit/core @scopekit/solid
```

Documentation and recipes live in the [repository](https://github.com/denislibs/scopekit#readme).
