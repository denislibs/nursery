# @nursery/solid

SolidJS primitives for [nursery](https://github.com/denislibs/nursery): scoped effects, async state, latest-wins calls, event streams and workers tied to the component lifecycle.

```bash
npm i @nursery/core @nursery/solid
```

Documentation and recipes live in the [repository](https://github.com/denislibs/nursery#readme).
