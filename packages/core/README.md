# @scopekit/core

Structured concurrency, cancellation and async utilities for the browser, built on `AbortSignal`, `Promise` and `AsyncIterable`. Zero dependencies, tree-shakeable subpaths.

```bash
npm i @scopekit/core
```

```ts
import { Scope } from '@scopekit/core';
import { debounce } from '@scopekit/core/iter';
```

Full documentation, recipes and framework adapters: [github.com/denislibs/scopekit](https://github.com/denislibs/scopekit#readme).
