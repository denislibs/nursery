# @nursery/core

Structured concurrency, cancellation and async utilities for the browser, built on `AbortSignal`, `Promise` and `AsyncIterable`. Zero dependencies, tree-shakeable subpaths.

```bash
npm i @nursery/core
```

```ts
import { Nursery } from '@nursery/core';
import { debounce } from '@nursery/core/iter';
```

Full documentation, recipes and framework adapters: [github.com/denislibs/nursery](https://github.com/denislibs/nursery#readme).
