# @scopekit/react

React hooks for [scopekit](https://github.com/denislibs/scopekit): scoped effects, async state, latest-wins calls, event streams and workers tied to the component lifecycle.

```bash
npm i @scopekit/core @scopekit/react
```

Documentation and recipes live in the [repository](https://github.com/denislibs/scopekit#readme).
